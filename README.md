# 🏐 VolleyManager

Sistema de gerenciamento de campeonatos de vôlei.

## Sobre o projeto

O VolleyManager é um projeto desenvolvido para praticar
lógica de programação, desenvolvimento web e construção
de APIs utilizando Python e Flask.

## Tecnologias

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git
